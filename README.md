# 💸 Walletly

A modern wallet application built using **React**, **TypeScript**, and **Turborepo** — with support for transactions, withdrawals, and wallet management.

## 🛠 Tech Stack

- **Turborepo** — Monorepo management
- **React 18** — Frontend UI
- **Recoil** + **Context API** — State management
- **TailwindCSS** + **Flowbite** — Styling and UI components
- **Node.js / Express.js** — Backend API (optional: describe if applicable)
- **Prisma** + **PostgreSQL** — Database ORM and storage (optional)
